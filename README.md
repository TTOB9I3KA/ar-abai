# AR-учебник «Ожившие портреты» — MVP

Один файл `index.html`, без сборки и зависимостей (jsQR и шрифты грузятся с CDN, нужен интернет).

## Файлы
- `index.html` — приложение: камера → распознавание QR → карточка с Абаем, сценой стиха, субтитрами и озвучкой.
- `qr-abai-tau.png` — QR-код (внутри текст `abai-tau`).
- `page-abai-tau.pdf` / `.png` — пример страницы учебника с текстом и QR, для печати или показа с экрана.

## Запуск на компьютере (Ubuntu)
```bash
cd ar-abai
python3 -m http.server 8000
```
Открыть http://localhost:8000 — на localhost камера разрешена. Покажите в веб-камеру QR с экрана телефона или распечатку.

## Запуск на телефоне
Камера в браузере телефона работает только по **HTTPS**. Варианты:
- **Netlify Drop** (проще всего): зайти на app.netlify.com/drop и перетащить папку `ar-abai` — получите https-ссылку.
- **GitHub Pages**: залить папку в репозиторий, включить Pages.
- **ngrok** для быстрой проверки: `python3 -m http.server 8000`, затем `ngrok http 8000` и открыть выданную https-ссылку на телефоне.

## QR-коды
Приложение принимает QR с текстом `abai-tau` или ссылку, оканчивающуюся на `#abai-tau`.
Когда будет постоянный адрес, лучше закодировать ссылку, например `https://ваш-сайт/#abai-tau`:
тогда обычная камера телефона откроет страницу сразу на нужном стихе.
```bash
python3 -c "import qrcode; qrcode.make('https://ваш-сайт/#abai-tau').save('qr.png')"
```

## Как добавить стихотворение
В `index.html` в объекте `POEMS` добавить новый ключ (он же текст QR): `title`, `author`, `note`, `lines.kk` / `lines.ru` и `cues` — для каждой строки шаг сцены `s` и жест Абая `g` (`point`, `open`, `down`, `chest`, `sleep`).
Для нового стиха нужна своя сцена (степь, зима и т.д.) — это следующий шаг.

## Озвучка
Сейчас читает встроенный синтезатор речи телефона (Web Speech API), строка за строкой, субтитры идут синхронно.
Русский голос есть почти везде. Казахского голоса на большинстве телефонов нет — тогда текст читает русский синтезатор, и приложение об этом пишет.
Следующий шаг — записать живое чтение (mp3) и разметить время начала каждой строки.
