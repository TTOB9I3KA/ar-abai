Положите сюда настоящую 3D-модель Абая с именем `abai.glb` — приложение подхватит её автоматически
вместо встроенной головы (шапка и борода-частицы тогда не добавляются, у модели будут свои).
Модель лучше облегчить до 1–3 МБ (например, gltf.report или `npx gltf-transform optimize abai.glb abai.glb`).
